# V2 合成器升级设计：距离经典合成器还差多少（2026-10-27）

对象：`rtl/v2_voice_engine_*.sv`、`rtl/v2_fx_lite.sv`、`rtl/v2_patch_bank.sv`、`rtl/v2_wavetable_loader.sv`。  
结论先行：**算力远远够，缺的是"功能件"**。

## 1. 现状盘点（读 RTL 得到的事实）

| 部件 | 当前实现 | 位置 |
| --- | --- | --- |
| 振荡器 | 2 个/声部，**朴素锯齿**（`phase[31:16] - 32768`） | `v2_voice_engine_mux.sv` |
| 幅度 | 包络/力度/配比用**2 的幂右移**近似（4 档），无乘法 | 同上 `oscillator_value()` |
| 包络 | 16 位线性，固定步长（A+4096 / D−256 / R−1024，S=49152） | 同上 |
| 滑音 | `step` 每拍 ±512 逼近 `target` | 同上 |
| 滤波 | **无**（仅 FX 里一个一阶低通） | — |
| LFO / 调制矩阵 | **无**（vibrato 已在计划中，未实现） | — |
| 声部 | 32 槽；满时**丢弃**（抢占策略已写入计划，未实现） | 同上 |
| 波表 | A/B/C 三表 + DPB patch bank + CRC/APPLY | `v2_patch_bank.sv` |
| FX | 增益 → 一阶低通 → 延迟 → 单 comb 混响 | `v2_fx_lite.sv` |
| 输出 | 16 bit 单声道 → I2S | `i2s_pcm5102a_tx.sv` |

## 2. 与经典合成器的差距评分

以三类经典参考：**减法合成**（Moog/Prophet 类）、**FM**（DX7）、**波表**（Serum/Braids 类）。

| 维度 | 经典做法 | 我们 | 完成度 | 缺失后果 |
| --- | --- | --- | --- | --- |
| 振荡器波形 | 多种 + 带限 + 同步 + PWM | 单锯齿、无带限 | **35%** | 高音混叠、音色单一 |
| 抗混叠 | polyBLEP / BLEP / mipmap | 无 | **0%** | 高音"脏" |
| 每声部滤波器 | 谐振 LPF，包络/键位调制 | **无** | **0%** | 做不出"温暖/扫频/酸"，**听感差距最大** |
| 包络 | 指数曲线、每参数独立、retrigger 模式 | 线性、两振荡器共用 | **45%** | 起音硬、做不了 FM 的"叮" |
| LFO | 多个、可同步、可路由 | 无 | **0%** | 无颤音/自动摇摆 |
| 调制矩阵 | 源×目标×深度，任意路由 | 固定（Z→增益/亮度/空间） | **10%** | 表情维度不足 |
| 声部管理 | 抢占、unison、portamento、力度分层 | 只找空槽，满则丢音 | **55%** | 密集演奏丢音 |
| FX | 合唱/相位/延迟/混响 | 延迟 + 单 comb | **30%** | 声音"干" |
| 输出 | 立体声 24 bit + 限幅 | 单声道 16 bit | **55%** | 偏"窄" |
| **综合** | — | — | **≈ 28%** | — |

**一句话**：骨架（32 声部、波表、双振荡器、时分复用）比多数参赛作品强，**但"减法合成最核心的那一级——每声部滤波器——完全缺失"**。

## 3. 关键事实：算力不是瓶颈

```text
每样本可用拍数：2083（100 MHz / 48 kHz）
当前扫描占用：约 35 拍（32 声部 × 1 拍）
余量：2048 拍，利用率 1.7%
```

把第 2 节所有缺件都补上，估算：

| 功能 | 每样本拍数 |
| --- | --- |
| polyBLEP 抗混叠（2 振荡器 × 4 拍 × 32） | 256 |
| 每声部二阶 SVF | 256 |
| 每算子包络（+2 拍 × 64） | 128 |
| LFO + 调制（32 声部 + 全局） | 96 |
| 立体声 + 限幅 | 32 |
| FX（延迟 + 3 comb 混响 + 合唱） | 约 300 |
| **合计** | **约 1,070 / 2,083 = 51%** |

**结论：补齐全套仍有 49% 余量。瓶颈在 DSP 与 BSRAM，不在时钟周期。**

## 4. 资源约束（真实数字）

| 资源 | 已用 | 余量 | 谁会吃掉 |
| --- | --- | --- | --- |
| LUT | 26% | 74% | 几乎不是问题 |
| FF | 13% | 87% | 不是问题 |
| BSRAM | 31% | 69% | FX 加长、mipmap 多八度表 |
| **DSP** | **65%** | **35%（10 个）** | **每声部滤波器** |
| 时序 | 93–100 MHz | 紧 | 任何新增组合逻辑 |

**注意**：当前样本通路是"无乘法器"设计（右移近似）。一旦引入滤波器，就要引入乘法——要么用 DSP（只剩 10 个），要么时分复用 2–4 个 DSP 轮流服务 32 声部（推荐）。

## 5. 升级设计（六阶段，按听感收益排序）

### P1 声部策略与表情（必须，约 0.5 天）

```text
· 抢占：released → oldest → lowest velocity → lowest voice_id
· 颤音：每声部 LFO phase/rate/depth（UQ8.8），调制相位增量
· APPLY 参数平滑：patch 切换时对增益/亮度做 64 样本淡入
```

验收：33 音符输入不丢音；vibrato 深度 20 音分可测；APPLY 无爆音。

### P2 每声部谐振低通（核心，约 1.5 天）

```text
二阶状态变量滤波器（SVF），Chamberlin 或 TPT 形式：
  lp += f * bp
  hp  = in - lp - q * bp
  bp += f * hp
每声部 2 乘 + 4 加 → 时分复用 2 个 DSP 服务 32 声部
调制：包络 × cutoff、键位跟踪、Z→cutoff
```

拍数：32 声部 × 8 拍 = 256 拍。  
验收：白噪输入扫频，−12 dB/oct 斜率正确；自激振荡可控（Q ≤ 0.9）。

### P3 振荡器质量（约 1 天）

```text
· polyBLEP 抗混叠（锯齿/方波各 2 处修正）
· 波形：锯齿 / 方波 / 三角 / 正弦（+ 波表）五选一
· 失谐：两振荡器 ±(0..20) 音分，可选 unison ×2
```

拍数：+256 拍。验收：C6 上扫频，混叠分量 < −40 dB。

### P4 调制矩阵（约 1 天）

```text
源：LFO1、LFO2、包络、力度、Z、滑音
目标：cutoff、pitch、振幅、pan、FX 发送
固定 8 条路由（不追求任意拓扑）
```

拍数：+96 拍。验收：每条路由可单独开关，深度可调。

### P5 FX 补全（约 1 天）

```text
· 合唱：2 条 1024 样本延迟 + LFO（BSRAM +2 块）
· 混响：3 comb + 2 allpass（BSRAM +6 块），按降级顺序可减到 1 comb
```

### P6 加法分量银行（可选，约 1 天）——**FPGA 原生卖点**

```text
每声部 8 个分量（基频 ×1..8），幅度由波表第 k 次谐波决定
32 × 8 = 256 个相位累加器
吞吐：256 × 48 kHz = 12.3 M 振荡器·样本/秒
拍数：256 × 4 = 1024 拍（仍有余量）
```

评审口径："加法按运算分量统计" → 256 个分量即 256 个振荡器。

## 6. 优先级与砍单

```text
必做（听感/合规）：P1 → P2 → P3
加分（差异化）：  P6（256 分量）> P4（矩阵）> P5（FX）
可砍：P5 的合唱、P4 的后 4 条路由
```

理由：

- **P2 是听感分水岭**：没有滤波器，其余优化都是修补；
- **P6 是"FPGA 优势"的唯一硬证据**：256 个并行分量，MCU 做不到；
- P4/P5 属于"完整度"，评委能感知但不惊艳。

## 11. 模式分离：Z 轴的双重职责（2026-10-27）

之前把 Z 同时用于"光标跟随速率 + 力度 + 调制深度"会三角色冲突。模式分离后不冲突：

| 模式 | Y/X | Z | Touch | 出音 |
| --- | --- | --- | --- | --- |
| LIVE / REC | 音高 / 运弓 | 跟随速率 + 力度 | 音符门控 | 手势实时出音 |
| PLAY | 仅显示，不产生音符 | **调制深度（旋钮）** | 选择调制目标 | Loop 事件表 |
| IDLE | — | — | — | 静音 |

同一根轴，由 `mode` 决定语义；两种模式不会同时生效，因此无需牺牲任何功能。

### 11.1 切换必须重基（rebase）

```text
进入 PLAY 时：z_ref = 当前 z，depth = clamp((z_ref − z) / z_span, 0, 1)
切回 LIVE 时：同样记录新基准，避免光标跳变
```

不重基的后果：切入 PLAY 瞬间深度立刻等于当前手位，参数跳变。

### 11.2 latch 与平滑

```text
平滑：z_smooth += (z − z_smooth) >> 4（≈5 ms）
死区：|Δz| < 2% 视为不动
latch：离开感应场后保持最后深度（否则一抬手音色回默认，无法调好）
```

### 11.3 调制目标与量程

```text
选择：电极 0–3（现场）或 PC 列表（配置，8 槽）
量程：cutoff ±4 八度 / Q ±0.5 / pitch ±50 音分 /
      delay time ±30% / feedback 0→0.6 / reverb mix 0→80% / drive 1→8×
公式：param = base + depth × range × enable
```

### 11.4 成本

```text
模式 mux 2 个 + rebase 寄存器 2 个 + 深度计算（1 乘 + 1 平滑）
约 12 拍/样本 = 0.6% 预算，不需要新协议
```

### 11.5 遥测新增

```text
mode（LIVE/REC/PLAY/IDLE）、当前深度、当前调制目标编号
```

PC 用它显示"现在 Z 在控制什么、深度多少"，与模式表对齐。

## 12. 滤波器与分量银行的详细设计（2026-10-27）

### 12.1 每声部 SVF（状态变量滤波器）

选用 **TPT（零延迟反馈）SVF**，比 Chamberlin 形式在高频更稳：

```text
g  = tan(pi * fc / fs)          （查表：256 项 cutoff → g）
k  = 1 / Q                      （Q 由参数给出，1/Q 查表）
a1 = 1 / (1 + g * (g + k))
a2 = g * a1
a3 = g * a2

v3 = x - ic2
v1 = a1 * ic1 + a2 * v3
v2 = ic2 + a2 * ic1 + a3 * v3
ic1 = 2*v1 - ic1
ic2 = 2*v2 - ic2
lp = v2        bp = v1        hp = x - k*v1 - v2
```

每样本每声部：**3 乘 + 6 加 + 2 状态**。时分复用 32 声部：

```text
32 × 8 拍 = 256 拍/样本（预算 2083）
乘法：3 × 32 = 96 次/样本 = 4.6 M/s，用 4 个 DSP 轮流即可
```

**数值格式**：状态 24 位 Q1.23，系数 18 位 Q1.17，中间 32 位。  
**稳定性**：`g` 限幅到 [0.001, 0.9]，`k` 限幅到 [0.05, 4]；`Q ≤ 10` 时不自激。

### 12.2 滤波器调制源（按 §11 的模式表）

| 源 | 作用 | 更新率 |
| --- | --- | --- |
| 包络 × 包络深度 | 起音开、释放关 | 每样本 |
| 键位跟踪 | 高音更亮 | 每音符一次 |
| **Z 深度（PLAY 模式）** | 手控亮度 | 200 Hz + 平滑 |
| 曲线相位表（可选） | 每音亮度轨迹 | 每样本 |

合成：

```text
cutoff_target = clamp(base * 2^(env*envDepth + keyTrack + zDepth*4) , 40 Hz, 18 kHz)
```

**注意**：指数映射用查表实现（`2^x` 的 256 项表），避免片上指数运算。

### 12.3 加法分量银行（256 分量）

| 项 | 规定 |
| --- | --- |
| 分量数 | 每声部 8，共 32 × 8 = 256 |
| 频率 | f_k = f0 × k（k=1..8），相位独立累加 |
| 幅度 | 由波表第 k 次谐波幅度决定（1024 点表做 8 次 DFT 子带积分，PC 侧预计算） |
| 包络 | 每分量共享声部包络（简化）；后续可每分量独立 |
| 相位 | 起音时各分量相位 = 0（相干起音，冲击感强）；可选随机相位（更厚） |

每样本每分量：

```text
phase_k += inc_k            1 拍
sample  = table_k[phase_k]  1 拍（查表）
acc    += sample * amp_k    2 拍（乘加）
合计 4 拍 × 256 = 1024 拍
```

剩余预算：2083 − 256（滤波）− 1024（分量）= 803 拍，够 FX 与遥测。

### 12.4 BSRAM 预算

| 项 | 用量 |
| --- | --- |
| 波表 A/B/C（1024×16） | 48 Kb |
| 分量幅度表（256×16） | 4 Kb |
| 滤波器系数表（2×256×18） | 9 Kb |
| LFO 形状表（2×256×16） | 8 Kb |
| 声部状态（32×约 300 bit） | 9.6 Kb |
| **合计** | **约 79 Kb** |

现有顶层用 31%，加这些约 +8% → 39%，仍有余量。

### 12.5 与其他模块的接口

```text
波表加载：v2_wavetable_loader 扩展一列"谐波幅度"（PC 预计算，8 个数）
滤波器参数：patch 里的 cutoff/Q/envDepth/keyTrack
分量开关：patch 里 partial_count（1..8），为 1 时行为等同单振荡器
```

**兼容性**：`partial_count=1` 时与当前 2 振荡器引擎行为一致，便于 A/B 与回退。

### 12.6 验收

| 项 | 判据 |
| --- | --- |
| SVF 频响 | 白噪扫频，−12 dB/oct 斜率误差 < 1 dB |
| 稳定性 | Q=10、cutoff=18 kHz 连续 1 分钟无自激 |
| 分量数 | partial_count=8 时频谱出现 8 个谐波峰 |
| 拍数 | 综合报告确认扫描周期 ≤ 1400 拍/样本 |
| 时序 | Fmax ≥ 100 MHz（真实 reader 路径接入后） |
