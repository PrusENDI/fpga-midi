# 系统设计总结（2026-10-25）

平台：Tang Primer 25K（GW5A-LV25MG121）。周期：7 天，已用约 1.5 天。

## 1. 总目标

交付「PC 上位机（参数控制 + 光标显示） + FPGA 实时合成器」。硬指标：≥4 复音（做 32 声部）、≤10 ms 延迟（目标 ≤5 ms）、音频必须由 FPGA 逐样本生成。

## 2. 总体结构

```text
                ┌──────────── FPGA ────────────┐
MGC3130 ──I2C──▶ 锁存 → 光标 → 出音规则 → 事件表
                                    │
                                    ▼
                            32 声部 × 2 振荡器（波表 + 包络 + 滑音）
                                    │
                                    ▼
                            混音 → FX → I2S → DAC

PC ──UART──▶ 参数下行（波表、包络、门控、音阶、FX）
PC ◀──UART── 遥测上行（光标、当前音符、声部占用）
```

PC 负责设计音色与显示轨迹，FPGA 负责实时发声。

## 3. 输入链路（已完成并验证）

| 环节 | 做法 | 关键参数 |
| --- | --- | --- |
| 传感 | MGC3130 电容三维 | 200 Hz，X/Y/Z 16 bit |
| 校准 | 每次录音调 `gestic_force_calibration()` | 接收器 `--force-calibration` |
| 光标 | 绝对映射，Z 控制跟随速率 | alpha 1.0→0.12，接合 30000 / 释放 36000 |
| 抗抖动 | 每帧位移 ≤0.02、触控冻结、接触前回滚、抬手平滑接续 | — |
| 触控漂移 | 接触使质心偏移 (−10071, +1433)，冻结规避 | 实测 `lead_20261025-121454` |

## 4. 事件链路（已完成并验证）

```text
光标轮廓 → 变分分段（Potts，DP 精确解）→ 音符表
代价 = Σ(轮廓 − 音级)² + λ·段数，段长 ≥ 4 tick
```

| 机制 | 说明 |
| --- | --- |
| 密度 | 滑块 → λ = 0.5·60^density |
| 门控 | `touch`（接触发声，时值=接触时长）/ `bow`（左右往返） |
| 同音重复 | 门控切分，落在同一音级 |
| 大跳 | 跨度 ≥3 音级且快速通过时不出经过音 |
| 时间模型 | 循环录制：绝对时间 → tick，超 128 回绕，后圈覆盖前圈 |
| 长度 | Auto length：按小节向上取整跟随录制长度 |

## 5. 音色链路（方案已定）

```text
① 采集一次划动（1.5–3 s）
② 时间去归一化 → 相位 0..1      ← 全部关键：手慢不再损失高频
③ 重采样 1024 点
④ 限带 32 次谐波                ← 把"画乱"从故障变成风格
⑤ 1024×16 bit 波表 → UART 下发 BRAM
⑥ FPGA：相位累加 → 查表 → 包络
```

已验证：线性映射平淡、tanh 波整形变亮、相位失真出金属感；固定旋律下四种音色可明确分辨。

## 6. 合成器（待写 RTL）

```text
32 声部 × 2 振荡器 = 64 个振荡器（≥32 达标）
每振荡器：1 相位加 + 3 查表 + 3 加权 + 1 包络 ≈ 13 clk
样本周期 2083 clk（100 MHz / 48 kHz）
64 × 13 = 832 clk → 占用 40%，余 60% 给 FX 与遥测
```

| 资源 | 用量 | 25K 占比 |
| --- | --- | --- |
| 波表 3×1024×16 | 48 Kb | 4.8% |
| 相位/包络 RAM | 7 Kb | 0.7% |
| FX 延迟线 + 混响 | 128 Kb | 12.7% |
| DSP 乘法 | 12.3 M/s | 0.4% |

时分复用已被组委会明确认可，无需物理并行。

## 7. 协议

```text
下行 CSR：0x60 square_mix / 0x64 exponent / 0x68 detune /
          0x6c 波表分块 / 0x70 ADSR / 0x74 门控与音阶
上行遥测：0x5A | x | y | z | note | flags | checksum（8 B @200 Hz）
```

## 10. 走过的弯路

| 尝试 | 结论 |
| --- | --- |
| 波导弦 | 音色调不出，弃用 |
| 分段 FFT 反推音色 | 两次统计压缩，区分度不足，弃用 |
| FM 调制波 | 可用但关联弱，备选 |
| **相位映射波表** | **采用** |

## 11. 一句话

手势曲线决定演奏（音高、节奏、力度），一次划动决定的波表决定音色，FPGA 只负责把两者实时合成。
