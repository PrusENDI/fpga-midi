# 时分复用振荡器引擎设计（128 算子 / 48 kHz）2026-10-25

目标：在 100 MHz 下、用一条流水线，每个 48 kHz 样本周期内完成 128 个算子的计算与混音。  
依据：组委会答疑确认"一个采样周期内轮询完成 N 个算子"等同 N 个振荡器同时活跃。

## 1. 时序预算

```text
样本周期      1 / 48000 = 20.833 µs
100 MHz       2083 clk / 样本
每算子预算    2083 / 128 = 16.3 clk
设计取        8 clk / 算子  →  128 × 8 = 1024 clk，余量 1059 clk
```

余量用于：每样本一次的混音收尾（约 20 clk）、FX（约 300 clk）、遥测（约 20 clk）。

## 2. 算子组织

```text
32 声部 × 4 算子 = 128 算子
每个声部：carrier0 + carrier1 + mod0 + mod1
模式 A（加法）：4 个正弦分量按 1.0 / 0.6 / 0.35 / 0.2 加权
模式 B（FM）  ：mod0 → carrier0，mod1 → carrier1（相位调制深度可调）
```

模式由 `timbre[1:0]` 选择，默认加法（易验证），FM 作为第二种音色。

## 3. 定点格式

| 量 | 位宽 | 格式 | 说明 |
| --- | --- | --- | --- |
| 相位 | 32 | 循环无符号 | 高 10 位查正弦表 |
| 增量 | 32 | 每样本相位步进 | `inc = f × 2^32 / 48000` |
| 包络 | 16 | 无符号满量程 | 65535 = 1.0 |
| 算子输出 | 16 | 有符号 | 正弦表输出 |
| 声部累加 | 24 | 有符号 | 4 算子加权和 |
| 混音累加 | 28 | 有符号 | 32 声部之和 |
| 输出 | 16 | 有符号 | 限幅后送 I2S |

## 4. 存储

```text
phase_ram  : 128 × 32     双口，读改写
inc_ram    : 128 × 32     单口写，双口读
env_ram    : 128 × 16
state_ram  : 128 × 8      {active, stage[1:0], voice_id[4:0]}
sine_rom   : 1024 × 16    1 BRAM，可选的 quarter 对称省一半
note_inc   : 128 × 32     音高 → 增量查找表（ROM，预计算）
```

`note_inc` 避免在 FPGA 里算 `2^(n/12)`：128 个 MIDI 音的增量全部预计算成常量表。

## 5. 流水线

```text
S0 FETCH   读 phase / inc / env / state
S1 ADD     phase += inc（含 FM 的相位偏移）
S2 LUT     sine[phase[31:22]]
S3 WEIGHT  wave × env >> 16，再 × 算子权重
S4 ACC     累加到当前声部的 24-bit 累加器
```

每算子 5 级，取 8 clk 一拍（含 RAM 建立时间与握手），128 算子 = 1024 clk。

**声部边界**：每 4 个算子切换一次声部，第 4 个算子完成时把 24-bit 累加写入 `mix_acc`。

## 6. 状态机

```text
IDLE
 → SAMPLE_START（每 20.833 µs 一次，由 sample_tick 触发）
 → OP_LOOP（128 次，算子计数器 0..127）
 → MIX_OUT（饱和到 16 bit，写 I2S FIFO）
 → FX（可选，级间复用）
 → TELEMETRY（每 N 个样本更新一次）
 → IDLE
```

## 7. 控制接口（与现有 CSR 对齐）

```text
0x80 VOICE_NOTE(voice)     {note[7:0], velocity[7:0]}  → 写 note_inc、env 触发
0x84 VOICE_OFF(voice)      进入 release
0x88 TIMBRE(voice)         模式 A/B 与权重
0x8c PITCH_BEND            全局半音偏移，signed 16
0x90 ADSR                  {A,D,S,R}
```

## 8. 验证方案

1. **golden 向量**：PC 端 `synth_reference.py` 生成 128 算子的相位/包络/输出序列，存为 CSV；
2. **仿真比对**：testbench 读同一组输入，逐样本比对输出，容差 ±1 LSB；
3. **资源与频率**：综合后确认 Fmax ≥ 100 MHz、时序收敛；
4. **板上**：单音 A4 测频率（示波器或频谱），32 声部同时测峰值与占用。

## 9. 与 PC 参考引擎的关系

`tools/synth_reference.py` 就是本设计的软件镜像：同样的 32 位相位、16 位包络、饱和混音。**RTL 与它逐样本一致**才算移植成功。

差异项（需要在 RTL 中固定）：

- 算子权重（1.0/0.6/0.35/0.2 的定点表示）；
- FM 调制深度；
- 混音右移位数（当前 PC 为 `>>2`）。
